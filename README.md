# jenusany.github.io

My personal portfolio. It's styled as a game-console home menu: press start, pick a channel.

- Content lives in `src/data/content.ts`, and the menu tiles in `src/data/channels.ts`.
- `npm run dev` starts the dev server at http://localhost:8080
- `npm run deploy` builds the site and publishes it to the `gh-pages` branch
